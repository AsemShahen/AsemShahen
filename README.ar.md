# نظام المحاسب — منظومة محاسبية وإدارية عربية شاملة

> **📖 متوفر بـ:** [العربية](#) | [English](README.md)

نظام محاسبة مالية وإدارة أعمال متكامل باللغة العربية (RTL) بعملة الريال السعودي (ر.س). يدعم **شركات متعددة**، لكل شركة قاعدة بيانات مستقلة (SQLite) قابلة للإقفال وترحيلها إلى سنة مالية جديدة.

## المميزات

- **شركات متعددة**: لكل شركة ملف قاعدة بيانات مستقل (`company_<id>.db`).
- **دليل حسابات حسب النشاط**: مخططات محاسبية جاهزة للشركات، السوبر ماركت، المصانع، المختبرات الطبية، والمستشفيات.
- **ضريبة القيمة المضافة السعودية (15%)**: تقارير ضريبية حسب الفترة، مع الحسابين 1401 (ضريبة مشتريات) و 2103 (ضريبة مبيعات).
- **الفاتورة الإلكترونية (ZATCA)**: توليد فاتورة إلكترونية متوافقة مع هيئة الزكاة والضريبة والجمارك (رمز QR بتنسيق TLV + ملف XML بصيغة UBL 2.1 مع تجزئة SHA-256 وتوقيع ECDSA P-256)، مع إرسال تلقائي (إبلاغ / اعتماد) عند حفظ كل فاتورة بيع.
- **طرق دفع شائعة**: نقدي، مدى، بطاقة ائتمانية، تحويل بنكي، سداد، Apple Pay، STC Pay، شيك، آجل، وغيرها.
- **المحاسبة الأساسية**: دفتر اليومية، دفتر الأستاذ، ميزان المراجعة، قائمة الدخل، الميزانية العمومية، وتقرير الضريبة.
- **الفوترة**: فواتير بيع وشراء مع ترحيل تلقائي للقيود، وتحصيل جزئي/آجل للعملاء والموردين.
- **إقفال السنة المالية**: قيد إقفال + قيد افتتاحي آلي مع ترحيل الأرصدة إلى السنة المالية الجديدة.
- **المستودعات والمخزون**: منتجات بباركود، مستودعات متعددة، حركات مخزون، جرد بقيود نقص/زيادة تلقائية، وشاشة **نقطة بيع (POS)** بمسح الباركود.
- **الموارد البشرية (HR)**: الأقسام، الموظفون، الحضور، إدارة الإجازات (اعتماد/رفض)، وتوليد الرواتب الشهرية مع ترحيل محاسبي تلقائي (مدين 5201 / دائن 2104).
- **نظام المشفى** (للمستشفيات): المرضى، الأطباء والأقسام، المواعيد، السجلات الطبية، وفوترة المرضى.
- **صلاحيات مقيدة لكل شركة**: يمكن منح المستخدم صلاحيات على شركات ونوافذ محددة.
- **إدارة قواعد البيانات**: من الإعدادات → قواعد البيانات يمكن إنشاء نسخة احتياطية، تنزيلها واستعادتها (من القائمة أو برفع ملف)، ضغط القاعدة (`VACUUM`)، وإصلاحها (فحص سلامة + إعادة بناء)، مع نسخة أمان تلقائية قبل أي استعادة.
- **واجهة ثنائية اللغة**: عربي (RTL) / إنجليزي مع مبدّل لغة داخل التطبيق.

## التشغيل

```
npm install
node seed.js
node server.js
```

ثم افتح `http://localhost:3001`.

- حساب المدير الافتراضي: **admin / admin123**
- مستخدم تجريبي (سوبر ماركت فقط): **cashier / cashier123**

## سير العمل

1. إنشاء شركة (الاسم، النشاط، رقم السجل، رقم ضريبة القيمة المضافة، معدل الضريبة، شهر بداية السنة المالية).
2. مراجعة دليل الحسابات الذي يتم تكوينه تلقائيًا حسب النشاط.
3. تسجيل قيود اليومية والفواتير والعملاء والموردين.
4. استعراض التقارير (ميزان المراجعة، قائمة الدخل، الميزانية، تقرير الضريبة).
5. إدارة المستودعات والمنتجات والجرد والبيع عبر نقطة البيع.
6. إدارة الموارد البشرية: الموظفون، الحضور، الإجازات، والرواتب الشهرية.
7. عند نهاية السنة: إقفال السنة المالية وفتح سنة جديدة تلقائيًا.

## الربط مع هيئة الزكاة (ZATCA)

1. سجّل منشأتك في بوابة هيئة الزكاة واحصل على بيانات الاعتماد (CSID) — ابدأ بوضع **Sandbox** للاختبار.
2. من شاشة **الإعدادات → الفاتورة الإلكترونية ZATCA**: فعّل الإرسال، حدد الوضع (Sandbox/Production)، وألصق CSID والمفتاح الخاص (PEM) والشهادة.
3. عند حفظ أي فاتورة بيع يُنشأ النظام تلقائيًا:
   - **رمز QR** بتنسيق TLV (اسم البائع، الرقم الضريبي، الوقت، الإجمالي، الضريبة + التجزئة والتوقيع عند التفعيل).
   - **ملف XML** بصيغة UBL 2.1 (فاتورة مبسطة B2C أو قياسية B2B حسب الرقم الضريبي للعميل).
   - إرسال تلقائي إلى منظومة فاتورة (إبلاغ للفواتير المبسطة، واعتماد للفواتير القياسية التي تتجاوز 1000 ر.س).
4. يمكن من قائمة فواتير البيع عرض تفاصيل الفاتورة الإلكترونية (QR + XML + الحالة) وإعادة الإرسال.

تُخزن حالة الإرسال لكل فاتورة (`zatca_status`): `not_configured` / `submitting` / `submitted` / `cleared` / `failed`.

## البنية

| الملف | الوصف |
|-------|-------|
| `server.js` | خادم Express (المنفذ 3001) + الملفات الثابتة |
| `lib/master-db.js` | سجل الشركات `data/app.db` |
| `lib/company-db.js` | مخطط قاعدة بيانات الشركة + طرق الدفع الافتراضية |
| `lib/charts.js` | دليل الحسابات حسب النشاط |
| `lib/accounting.js` | العمليات المحاسبية + إقفال السنة |
| `lib/invoices.js` | الفوترة والتحصيل والترحيل التلقائي + توليد الفاتورة الإلكترونية |
| `lib/parties.js` | العملاء والموردون |
| `lib/inventory.js` | المستودعات والمنتجات والمخزون والجرد ونقطة البيع |
| `lib/hr.js` | الموارد البشرية: الأقسام والموظفون والحضور والإجازات والرواتب |
| `lib/hospital.js` | نظام المشفى |
| `lib/db-tools.js` | نسخ / استعادة / ضغط / إصلاح قواعد البيانات |
| `lib/zatca/` | الفاتورة الإلكترونية ZATCA (QR + XML + التوقيع + الإرسال) |
| `seed.js` | بيانات تجريبية لـ 5 شركات |
| `public/` | واجهة الويب (Vue 3 SPA بدون خطوة بناء) |

## تابات الإعدادات

- **بيانات الشركة**: اسم المنشأة، نسبة الضريبة، رقم السجل، الرقم الضريبي، العملة، شهر بداية السنة المالية، العنوان، الهاتف، والبريد الإلكتروني.
- **الربط مع هيئة الزكاة (ZATCA)**: تفعيل الإرسال التلقائي، اختيار الوضع (Sandbox/Production)، وحفظ بيانات الاعتماد CSID والمفتاح الخاص (PEM) والشهادة وOTP.
- **قواعد البيانات** (للمدير فقط): إنشاء نسخة احتياطية فورية، تنزيل/استعادة النسخ (من القائمة أو برفع ملف `.db`)، ضغط القاعدة، وإصلاحها. تُنشأ نسخة أمان تلقائية قبل كل استعادة.
