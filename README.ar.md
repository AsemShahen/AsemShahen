# نظام المحاسب — منظومة محاسبية وإدارية عربية شاملة

> **📖 متوفر بـ:** [العربية](#) | [English](README.md)

نظام محاسبة مالية وإدارة أعمال متكامل باللغة العربية (RTL) بعملة الريال السعودي (ر.س). يدعم **شركات متعددة**، لكل شركة قاعدة بيانات مستقلة (SQLite) قابلة للإقفال وترحيلها إلى سنة مالية جديدة.

## المميزات

- **شركات متعددة**: لكل شركة ملف قاعدة بيانات مستقل (`company_<id>.db`)، وكل حساب مرتبط بشركة واحدة فقط. مدير المنصة (يُنشأ عند التنصيب) يُنشئ الشركات ويدقّق فيها، بينما تُدار كل شركة باستقلالية تامة بواسطة مديرها.
- **فروع متعددة**: يمكن للشركة تعريف عدة **فروع** (الرمز، الاسم، المدير، الهاتف، العنوان، ملاحظات) مع فرع افتراضي. يمكن ربط المستودعات والمستخدمين والفواتير والقيود اليومية بفرع، ويمكن تصفية كل التقارير ولوحات المعلومات حسب الفرع. إدارة الفروع متاحة لمدير الشركة فقط، وتُربط السجلات الحالية تلقائياً بالفرع الافتراضي.
- **دليل حسابات حسب النشاط**: مخططات محاسبية جاهزة للشركات، السوبر ماركت، المصانع، المختبرات الطبية، المستشفيات، المطاعم/الكفيهات، والفنادق/الشقق المفروشة.
- **ضريبة القيمة المضافة السعودية (15%)**: تقارير ضريبية حسب الفترة، مع الحسابين 1401 (ضريبة مشتريات) و 2103 (ضريبة مبيعات).
- **الفاتورة الإلكترونية (ZATCA)**: توليد فاتورة إلكترونية متوافقة مع هيئة الزكاة والضريبة والجمارك (رمز QR بتنسيق TLV + ملف XML بصيغة UBL 2.1 مع تجزئة SHA-256 وتوقيع ECDSA P-256)، مع إرسال تلقائي (إبلاغ / اعتماد) عند حفظ كل فاتورة بيع.
- **طرق دفع شائعة**: نقدي، مدى، بطاقة ائتمانية، تحويل بنكي، سداد، Apple Pay، STC Pay، شيك، آجل، وغيرها.
- **المحاسبة الأساسية**: دفتر اليومية، دفتر الأستاذ، ميزان المراجعة، قائمة الدخل، الميزانية العمومية، وتقرير الضريبة.
- **الفوترة**: فواتير بيع وشراء مع ترحيل تلقائي للقيود، وتحصيل جزئي/آجل للعملاء والموردين.
- **إقفال السنة المالية**: قيد إقفال + قيد افتتاحي آلي مع ترحيل الأرصدة إلى السنة المالية الجديدة.
- **المستودعات والمخزون**: منتجات بباركود، مستودعات متعددة، حركات مخزون، جرد بقيود نقص/زيادة تلقائية، وشاشة **نقطة بيع (POS)** بمسح الباركود. وفي المطاعم/الكفيهات تعرض نقطة البيع الوجبات المصنّعة فقط (المنتجات التي لها وصفة).
- **الموارد البشرية (HR)**: الأقسام، الموظفون، الحضور، إدارة الإجازات (اعتماد/رفض)، وتوليد الرواتب الشهرية مع ترحيل محاسبي تلقائي (مدين 5201 / دائن 2104).
- **نظام المشفى** (للمستشفيات): المرضى، الأطباء والأقسام، المواعيد، السجلات الطبية، وفوترة المرضى.
- **نظام المطاعم والكفيهات — الوصفات والتكلفة** (للمطاعم/الكفيهات): تعريف **وصفة (BOM)** لكل وجبة تربط المنتج الجاهز بمواده الخام بالكميات ونسبة الهدر، مع **تكلفة الحصة/الدفعة** وهامش الربح تلقائياً، وإصدار **أوامر تصنيع** تخصم المواد من المستودع وتضيف الوجبة الجاهزة وتحدّث تكلفتها (أساس تكلفة المبيعات). وتُصنَّع الوجبة **تلقائياً عند البيع** إذا كان رصيد الجاهز غير كافٍ.
- **نظام الفنادق والشقق المفروشة** (للفنادق/الشقق المفروشة): تعريف **أنواع الوحدات** (فردية، مزدوجة، جناح، شقة مفروشة) بأسعارها وسعتها، و**الغرف/الوحدات** وحالاتها (متاحة، مشغولة، قيد التنظيف، صيانة، خارج الخدمة)، و**سجل النزلاء**، و**الحجوزات** مع منع تعارض الحجز على الوحدة نفسها، و**تسجيل الدخول والخروج**، و**حساب النزيل (Folio)** ببنود الإقامة والخدمات (مغسلة، خدمة الغرف، إفطار، توصيل...) والدفعات والعربون، مع ترحيل الإيراد وضريبة القيمة المضافة وذمم النزلاء إلى القيود تلقائياً عند تسجيل الخروج.
- **نظام التصنيع** (للمصانع/الشركات الصناعية): تعريف **قوائم التصنيع (BOM)** التي تربط كل منتج تام بمواده الأولية بالكميات والهدر وكمية الناتج، وإنشاء **أوامر تصنيع** (الكمية المخطّطة، التواريخ، المستودع)، و**صرف المواد** من المخزون، وتسجيل **المصروفات المباشرة وغير المباشرة** (أجور، كهرباء، إيجار، إهلاك، صيانة...)، ثم **إتمام الإنتاج** الذي يرحّل تكلفة (مواد أولية → إنتاج تحت التشغيل `1312` → إنتاج تام `1313`) ويضيف الكمية المنتجة للمخزون ويحدّث تكلفة المنتج. ويمكن **إلغاء الأمر** مع عكس كل الحركات المخزنية والقيود المرتبطة، مع **لوحات وتقارير** تعرض الإنتاج تحت التشغيل وتحليل التكلفة والمصروفات حسب البند والإنتاج الشهري.
- **أدوار وصلاحيات مقيدة بالشركة**: ثلاثة أدوار — `platform` (ينشئ الشركات ويدقّق فيها للقراءة فقط)، و`admin` (تحكم كامل داخل شركته فقط)، و`user` (صلاحيات محددة لكل نافذة داخل شركته). وتُقيَّد نوافذ الصلاحيات حسب نوع نشاط الشركة (مثلاً نوافذ المشفى للمستشفيات، ونوافذ الفنادق للفنادق/الشقق المفروشة، ونوافذ التصنيع للمصانع، والمستودعات/نقطة البيع لأنشطة البضائع، والوصفات/التصنيع للمطاعم والكفيهات فقط). لا يستطيع أي حساب الوصول إلى بيانات شركة أخرى إطلاقاً.
- **إدارة قواعد البيانات**: من الإعدادات → قواعد البيانات يمكن إنشاء نسخة احتياطية، تنزيلها واستعادتها (من القائمة أو برفع ملف)، ضغط القاعدة (`VACUUM`)، وإصلاحها (فحص سلامة + إعادة بناء)، مع نسخة أمان تلقائية قبل أي استعادة.
- **ربط الواتساب**: إرسال فواتير البيع والشراء وإيصالات نقطة البيع وكشوفات الحساب للعملاء والموردين عبر واتساب — مع إعدادات وقوالب رسائل لكل شركة. يعمل مباشرة برابط wa.me، أو يرسل تلقائياً عند إضافة بيانات WhatsApp Business Cloud API.
- **المحادثة الداخلية**: تواصل فوري بين موظفي الشركة عبر **قناة عامة** وقنوات خاصة بكل قسم ومحادثات خاصة مباشرة (رسائل كتابية، رسائل صوتية، صور ومستندات PDF/Word/Excel وأي ملفات، ومكالمات صوتية وفيديو مباشرة). السجل كامل ودائم لكل الشركة، ولا يستطيع الموظفون حذف أي رسالة — الحذف (أو تطهير قناة) متاح لمدير الشركة فقط مع تسجيل كل عملية في سجل المراجعة.
- **سجل عمليات المستخدمين**: تدقيق شامل لكل عملية يقوم بها المستخدمون — الإضافة، التعديل، الحذف، البحث، الطباعة، الاستيراد، والتصدير، إضافةً إلى تسجيل الدخول والخروج. ويُحفظ لكل عملية الوقت والتاريخ، والمستخدم ودوره، والشركة، ونوع العملية، وملخصها، وعنوان IP، واسم الجهاز/المتصفح، وحالة التنفيذ (نجاح/فشل)، مع شاشة مخصّصة للعرض والتصفية حسب الفترة والمستخدم والنوع والوحدة والبحث النصي، وتصدير ومعاينة قبل الطباعة. تُخزَّن السجلات مركزياً في قاعدة بيانات المنصة، ويمكن لمدير الشركة رؤية عمليات شركته، ولمدير المنصة رؤية عمليات كل الشركات. وتظهر بيانات **عنوان IP واسم الحاسب** مخفيةً على شكل كلمة مرور (••••••••) ولا يكشفها إلا مدير الشركة أو مدير المنصة بزر إظهار/إخفاء.
- **واجهة ثنائية اللغة**: عربي (RTL) / إنجليزي مع مبدّل لغة داخل التطبيق.
- **متجاوب بالكامل مع الجوال**: تصميم متجاوب يبدأ من الجوال — قائمة جانبية منزلقة بزر قائمة (هامبرغر)، بطاقات ونماذج تتكدس تلقائياً، جداول بتمرير أفقي، نوافذ منبثقة بنمط القاع على الهاتف، وتجربة محادثة مخصّصة للجوال بقسمين (قائمة/محادثة).

## التشغيل

```
npm install
node seed.js
node server.js
```

ثم افتح `http://localhost:3001`.

عند فتح البرنامج تظهر **صفحة سجل الشركات العامة**: جدول بكل الشركات (الاسم، النشاط، السجل التجاري، الرقم الضريبي، بداية/نهاية السنة المالية، تاريخ الإنشاء) مع أزرار إجراءات، ولا يحتاج عرض القائمة إلى تسجيل دخول:

- **إنشاء شركة جديدة** و**تعديل** و**حذف** تفتح أولاً نافذة تسجيل دخول مدير المنصة، وبعد المصادقة تُفتح النافذة المطلوبة. وعند إنشاء الشركة يُنشأ أول مدير لها، ويمكن إضافة مدراء آخرين لاحقاً من **المستخدمون والصلاحيات** داخل الشركة. الحذف يزيل الشركة وكل ملفات قاعدة بياناتها نهائياً.
- **فتح** يفتح نافذة تسجيل دخول الشركة؛ يدخل مدير الشركة أو أي مستخدم من موظفيها إلى شركته فقط.

حسابات الدخول الافتراضية:

- حساب مدير المنصة (بدون شركة): **admin / admin123** — لإنشاء الشركات وتعيين مدرائها وتعديل بياناتها وحذفها.
- حساب مدير شركة تجريبي (لكل شركة): **admin / admin123** — استخدم زر **فتح** على سطر الشركة ثم ادخل لإدارتها.
- مستخدم تجريبي (سوبر ماركت فقط): **cashier / cashier123** — استخدم **فتح** على سطر السوبر ماركت ثم ادخل.

## سير العمل

> **مدير المنصة** يدير سجل الشركات (الخطوتان 1-2) من صفحة سجل الشركات. ثم يدخل **مدير كل شركة** إلى شركته ليدير أعمالها (الخطوات 3-7). ولا يمكن لمدير الشركة رؤية أو إدارة أي شركة أخرى.

1. إنشاء شركة (الاسم، النشاط، رقم السجل، رقم ضريبة القيمة المضافة، معدل الضريبة، بداية ونهاية السنة المالية) وتعيين أول مدير لها.
2. مراجعة دليل الحسابات الذي يتم تكوينه تلقائيًا حسب النشاط.
3. تسجيل قيود اليومية والفواتير والعملاء والموردين.
4. استعراض التقارير (ميزان المراجعة، قائمة الدخل، الميزانية، تقرير الضريبة).
5. إدارة المستودعات والمنتجات والجرد والبيع عبر نقطة البيع. وفي المطاعم/الكفيهات تُعرَّف الوصفات وتُصنَّع الوجبات، وتعرض نقطة البيع الوجبات المصنّعة فقط. وفي المصانع تُعرَّف قوائم التصنيع وأوامرها وتُصرف المواد وتُسجَّل المصروفات المباشرة وغير المباشرة ويُتمّ الإنتاج. وفي الفنادق/الشقق المفروشة تُعرَّف أنواع الوحدات والغرف، وتُسجَّل الحجوزات والنزلاء.
6. إدارة الموارد البشرية: الموظفون، الحضور، الإجازات، والرواتب الشهرية.
7. عند نهاية السنة: إقفال السنة المالية وفتح سنة جديدة تلقائيًا.

## الربط مع هيئة الزكاة (ZATCA)

1. سجّل منشأتك في بوابة هيئة الزكاة واحصل على بيانات الاعتماد (CSID) — ابدأ بوضع **Sandbox** للاختبار.
2. من شاشة **الإعدادات → الفاتورة الإلكترونية ZATCA**: فعّل الإرسال، حدد الوضع (Sandbox/Production)، وألصق CSID والمفتاح الخاص (PEM) والشهادة.
3. عند حفظ أي فاتورة بيع يُنشأ النظام تلقائيًا:
   - **رمز QR** بتنسيق TLV (اسم البائع، الرقم الضريبي، الوقت، الإجمالي، الضريبة + التجزئة والتوقيع عند التفعيل).
   - **ملف XML** بصيغة UBL 2.1 (فاتورة مبسطة B2C أو قياسية B2B حسب الرقم الضريبي للعميل).
   - إرسال تلقائي إلى منظومة فاتورة (إبلاغ للفواتير المبسطة، واعتماد للفواتير القياسية التي تتجاوز 1000 ر.س).
4. يمكن من قائمة فواتير البيع عرض تفاصيل الفاتورة الإلكترونية (QR + XML + الحالة) وإعادة الإرسال.

تُخزن حالة الإرسال لكل فاتورة (`zatca_status`): `not_configured` / `submitting` / `submitted` / `cleared` / `failed`.

## نظرة عامة على الواجهة

جميع الشاشات تدعم العربية والإنجليزية: لوحة التحكم، المخطط المحاسبي، قيود اليومية، دفتر الأستاذ، ميزان المراجعة، قائمة الدخل، الميزانية العمومية، تقرير الضريبة، فواتير البيع والشراء، العملاء والموردون، المخزون والأرصدة، نقطة البيع، الوصفات والتكلفة، التصنيع، نظام تصنيع المصانع (لوحة التصنيع، قوائم BOM، أوامر التصنيع، المصروفات، التقارير)، الموظفون والأقسام، الإجازات، الرواتب والأجور، نظام الفنادق (الغرف والوحدات، سجل النزلاء، الحجوزات، الخدمات، حسابات النزلاء والفوترة)، نظام المشفى، المحادثة الداخلية، الفروع، إقفال السنة، الإعدادات، المستخدمون والصلاحيات، وسجل عمليات المستخدمين.

## المحادثة الداخلية

- **قنوات تلقائية**: قناة عامة لكل موظفي الشركة + قناة لكل قسم من أقسام الموارد البشرية، تُنشأ تلقائياً.
- **مراسلة مباشرة**: أي موظف يستطيع التواصل مباشرة مع أي موظف آخر داخل الشركة، مع مؤشر التواجد الفوري وعداد الرسائل غير المقروءة.
- **محتوى غني**: رسائل كتابية، تسجيل صوتي فوري، صور، ومستندات (PDF / Word / Excel / أي ملف حتى 30MB) تظهر داخل المحادثة.
- **مكالمات مباشرة**: مكالمات صوتية وفيديو بين الموظفين عبر WebRTC (مباشر بين الطرفين دون خوادم وسيطة، والإشارة تمر عبر النظام). الاتصال يُعاد بناؤه تلقائياً عند الفشل وتُخزَّن مرشحات ICE مؤقتاً حتى اكتمال التفاوض، مع دعم خادم TURN قابل للتهيئة للشبكات المقيدة عبر متغيرات البيئة `RTC_TURN_URL` و`RTC_TURN_USERNAME` و`RTC_TURN_CREDENTIAL` أو قائمة كاملة عبر `RTC_ICE_JSON`.
- **السجل دائم**: تُحفظ كل الرسائل في قاعدة بيانات الشركة وتُضمن مع النسخ الاحتياطي والاستعادة، ولا يُحذف منها شيء من الموظفين.
- **مشاركة مدير المنصة**: يمكن لمدير المنصة فتح محادثة أي شركة من لوحة المنصة والمشاركة في قنواتها ومحادثاتها المباشرة (تبقى عمليات الحذف مقصورة على مدير الشركة).
- **إشراف المدير**: حذف رسالة واحدة أو تطهير قناة كاملة متاحان لمدير الشركة فقط، وكل حذف يُسجَّل في سجل المراجعة داخل قاعدة بيانات الشركة.
- **تنظيم الأعضاء** (للمدير): تعيين قسم كل موظف وعرض اسمه ومسماه الوظيفي من شريط المحادثات.
